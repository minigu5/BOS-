## 4. 동영상 파일 준비 (파일명 규칙)

```

```

## 5. Step 1 — 전처리 실행 (`1_preprocess.py`)

동영상에서 **Optical Flow(BOS 신호)** 를 추출하여 `.npy` 파일로 저장합니다.

### 기본 실행 (권장)

```bash
python 1_preprocess.py
```

### 옵션을 바꿔서 실행

```bash
python 1_preprocess.py \
  --input_dir  input_videos \   # 동영상 폴더 (기본값)
  --output_dir output_dataset \ # 출력 폴더 (기본값)
  --chunk_size 16 \             # 청크당 프레임 수 (기본값 16)
  --overlap    8 \              # 청크 간 겹치는 프레임 수 (기본값 8)
  --resize_h   224 \            # 프레임 높이 리사이즈 (기본값 224)
  --resize_w   224 \            # 프레임 너비 리사이즈 (기본값 224)
  --ema_alpha  0.05             # 배경 갱신 속도 (기본값 0.05)
```

## 7. 결과 해석

### 평가 지표 의미

| 지표 | 의미 | 이 시스템에서의 중요도 |
|------|------|------------------------|
| **Precision** | 가스 누출로 예측한 것 중 실제 가스 누출 비율 | ⭐⭐⭐ (오탐 직결) |
| **Recall** | 실제 가스 누출 중 탐지한 비율 | ⭐⭐ (미탐 직결) |
| **F1** | Precision과 Recall의 조화 평균 | ⭐⭐ |
| **Accuracy** | 전체 정확도 | ⭐ (불균형 데이터에서 오해 소지) |

### 혼동 행렬(Confusion Matrix) 읽기

```
                예측: 정상(N)   예측: 가스(G)
실제: 정상(N)      TN (잘함)      FP (오탐) ← 줄여야 함
실제: 가스(G)      FN (미탐)      TP (잘함)
```

- **FP (False Positive) = 오탐**: 정상인데 "가스 누출!" 경보 → 불필요한 대피/조업 중단
- **FN (False Negative) = 미탐**: 실제 가스 누출인데 탐지 못함 → 안전 위험

### 저장된 모델 파일

```
checkpoints/
└── best_model.pth    ← Validation F1이 가장 높았던 에포크의 가중치
```

## 8. 오탐(FP) 줄이기

오탐을 줄이는 방법은 **두 가지** 손잡이를 조절하는 것입니다.

### 방법 A: 분류 임계값(threshold) 올리기 (즉시 적용)

임계값 스윕 테이블에서 **FP = 0** 또는 원하는 수준이 되는 threshold를 찾아  
학습 재실행 없이 추론 시 적용합니다.

```bash
# 예: threshold를 0.65로 설정하면 FP=0 (단, FN 증가)
python 2_train.py --threshold 0.65
```

### 방법 B: FP 페널티 강도(fp_weight) 올리기 (재학습 필요)

학습 손실함수 자체에서 오탐 패턴 학습을 억제합니다.

```bash
# fp_weight 기본값: 2.0 → 3.0으로 올려 재학습
python 2_train.py --fp_weight 3.0
```

### 권장 조정 순서

```
1단계: 기본값으로 학습 (fp_weight=2.0, threshold=0.5)
         ↓ 임계값 스윕 테이블 확인
2단계: threshold 조정 (재학습 없이 FP↓ 시도)
         ↓ 여전히 FP가 많다면
3단계: fp_weight 올려서 재학습 (2.0 → 3.0 → 4.0)
         ↓ Recall이 너무 낮아진다면
4단계: fp_weight와 threshold 조합 탐색
```

> **주의:** fp_weight를 너무 높이면 모델이 항상 "정상(N)"으로만 예측하게 됩니다.  
> Recall이 0.5 아래로 떨어지면 fp_weight를 낮춰야 합니다.

## 9. 파라미터 참고표

### 전처리 파라미터 (`1_preprocess.py`)

| 파라미터 | 기본값 | 설명 | 언제 바꾸나 |
|----------|--------|------|------------|
| `--chunk_size` | 16 | 청크당 프레임 수 | 더 긴 시간 문맥이 필요하면 32로 |
| `--overlap` | 8 | 청크 간 오버랩 | 데이터 부족 시 12로 늘려 청크 수 증가 |
| `--resize_h/w` | 224 | 프레임 해상도 | 속도 우선이면 112로 줄임 |
| `--ema_alpha` | 0.05 | 배경 갱신 속도 | 카메라가 흔들리면 0.02로 낮춤 |

### 학습 파라미터 (`2_train.py`)

| 파라미터 | 기본값 | 설명 | 언제 바꾸나 |
|----------|--------|------|------------|
| `--img_size` | 112 | 모델 입력 해상도 | 정확도 우선이면 224 (4배 느려짐) |
| `--batch_size` | 8 | 배치 크기 | GPU 메모리 부족 시 4로 줄임 |
| `--num_epochs` | 50 | 최대 에포크 | 데이터 많으면 100으로 늘림 |
| `--fp_weight` | 2.0 | 오탐 페널티 | 오탐이 많으면 3.0~4.0으로 |
| `--threshold` | 0.5 | 분류 임계값 | 스윕 테이블 보고 조정 |

## 10. 자주 묻는 질문 / 오류 해결

### Q1. `파일명에서 레이블을 파악할 수 없습니다.` 오류가 납니다.

파일명이 `_G` 또는 `_N`으로 끝나지 않습니다.  
파일명을 확인하세요. 확장자 바로 앞이어야 합니다.

```
틀림: gas_leak.mp4,  factory_G_test.mp4 (G 뒤에 다른 문자가 있음)
맞음: gas_leak_G.mp4,  factory_test_G.mp4
```

---

### Q2. `데이터가 없습니다. 먼저 1_preprocess.py를 실행하세요.` 오류가 납니다.

전처리를 먼저 실행해야 합니다.

```bash
python 1_preprocess.py   # 먼저 실행
python 2_train.py        # 그 다음 실행
```

---

### Q3. `Gas와 Normal 비디오가 최소 1개씩 있어야 합니다.` 오류가 납니다.

`output_dataset/Gas/` 또는 `output_dataset/Normal/` 중 하나가 비어 있습니다.  
두 클래스 동영상이 모두 `input_videos/` 에 있는지 확인하세요.

---

### Q4. GPU가 없어서 학습이 너무 느립니다.

에포크 수와 배치 크기를 줄이고, 해상도를 낮추세요.

```bash
python 2_train.py --num_epochs 30 --batch_size 4 --img_size 64
```

---

### Q5. 동영상이 많은데 전처리가 너무 오래 걸립니다.

해상도를 줄이면 전처리 속도가 빨라집니다.

```bash
python 1_preprocess.py --resize_h 112 --resize_w 112
```

## 전체 실행 흐름 요약

```
① input_videos/ 폴더 생성 후 동영상 파일 넣기
   (파일명 끝에 _G 또는 _N 필수)
         ↓
② python 1_preprocess.py
   → output_dataset/Gas/, output_dataset/Normal/ 생성 확인
         ↓
③ python 2_train.py
   → 학습 로그 확인, checkpoints/best_model.pth 생성 확인
         ↓
④ 임계값 스윕 테이블에서 FP=0 또는 목표치의 threshold 선택
   → 필요 시 fp_weight 조정 후 재학습
```
